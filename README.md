# Interview-Cracker

Greenroom is a live interview co-pilot designed for interview practice and live cue support.

## Stack
- Client: Vite + vanilla JS
- Server: Express + Anthropic API
- Capture: browser microphone and system audio hooks

## Quick start

1. Copy `.env.example` to `.env` and add your API keys.
2. Install dependencies:
   npm install
3. Start both client and server:
   npm run dev
4. Open the app in the browser at http://localhost:4173

## Structure

- `client/` browser app
- `server/` backend routes and prompt logic
- `docs/` design notes

## Ethics

This project is intended for interview preparation and mock practice. Using it during actual interviews may be considered deceptive or unethical depending on the jurisdiction and process.
